# Личный дневник настроения — WPF (.NET 8)

Демонстрационный интерфейс приложения «Личный дневник настроения с аналитикой».

## Требования

- Windows 10/11.
- Visual Studio 2022 версии 17.8 или новее с рабочей нагрузкой «Разработка классических приложений .NET».
- .NET 8 SDK (проверяется командой `dotnet --list-sdks`).

## Как запустить

1. Полностью распакуйте ZIP-архив в отдельную папку.
2. Откройте `MoodJournalWpf.sln` в Visual Studio.
3. В обозревателе решений щёлкните проект `MoodJournalWpf` правой кнопкой и выберите «Назначить запускаемым проектом» при необходимости.
4. Выберите «Сборка → Пересобрать решение» или нажмите Ctrl+Shift+B.
5. Убедитесь, что сборка завершилась успешно, затем нажмите F5.

Если Visual Studio не находит exe, сначала проверьте **Список ошибок** и **Вывод → Сборка**. Ошибка поиска exe означает, что он отсутствует по ожидаемому пути: причину следует искать в результате сборки или настройках запуска.

## Возможности

- Выбор настроения по шкале от 1 до 5.
- Выбор нескольких активностей и добавление заметки.
- Сохранение новых записей в памяти приложения.
- Главная страница, история записей, аналитика.
- Автоматический расчёт среднего балла, количества записей, лучшего дня и наиболее частой активности.
- Столбчатые графики настроения за 7 дней.
- Семь демонстрационных записей с датами относительно текущего дня.

## Ограничения демо

Записи хранятся только до закрытия приложения. В этой версии нет подключения к MS SQL Server и авторизации. Проект демонстрирует внешний вид и взаимодействия, а не полную реализацию технического задания.

## Технические сведения

- Целевая платформа: `net8.0-windows`.
- WPF: `<UseWPF>true</UseWPF>`.
- Тип приложения: `WinExe`.
- Сторонние NuGet-пакеты не используются.
- Для Windows не требуется `EnableWindowsTargeting`.

Папки `bin` и `obj` специально не включены в архив. Исполняемый файл создаётся Visual Studio после успешной сборки.
